# Caroá Maps

App de campo dos lotes em Dúvida: a ortofoto do pacote (feita pelo botão 📍 do
Vetorizador Toolkit no QGIS), o GPS, o "✓ Conferido" e o relatório do dia em PDF.
Os mapas e as marcas ficam só no aparelho; este site leva só o app.

Versão 1.1.

## No iPhone (para testes)
1. Abrir este endereço no **Safari**.
2. Compartilhar (⬆) → **Adicionar à Tela de Início**.
3. Abrir o Caroá Maps pela tela de início (permitir a Localização).
4. O pacote: no WhatsApp, abrir o `CAROA_MAPS_….zip` → compartilhar → **Salvar em
   Arquivos**; no app, **📂 Abrir arquivo** e escolher o .zip.

Depois da primeira abertura com internet, o app abre sem sinal.

No Android, o recomendado é o APK (CaroaMaps_vX_Y.apk, que o plugin põe na pasta
do campo): ele recebe o .zip direto pelo "Abrir com" do WhatsApp.
